TF2Speech v{version} - what's new
==============================

v1.1.2
------
- Updates: TF2Speech now looks for a new version on GitHub when it starts. A bar at the top of the window (never
  a pop-up) offers "Update now": it downloads the new version, checks it against GitHub's checksum, swaps it in
  and restarts. Settings, voices, sounds and downloaded tools are kept; the old exe is kept as
  TTS_TF2_64BIT.exe.old, and if tts.cfg changed, yours is kept as tts.cfg.old. Settings > Updates switches the
  check off or runs it now. The check is a normal request to GitHub - nothing about you or your chat is sent.
- Emoji and text smileys are said by name in every voice, the way Windows' David does it: 🙂 "slightly smiling
  face", :) "smiley face", <3 "heart". A row of the same emoji is said once, and at most 8 per message.
- Piper voices spell out short capital abbreviations (PST, GG, TF2, AFK) instead of saying them as words.
- DJ: song requests for age-restricted YouTube videos are denied ("your request was denied, it's age
  restricted") - TF2Speech never uses anyone's YouTube login.
- Piper and the DJ's helper programs run at a lower priority, so TF2 always goes first (fewer micro-stutters
  when someone talks in a Piper voice or a YouTube song starts).


v1.1.1
------
- DECtalk songs cut off by TF2's chat length limit are sung (the unfinished last note is dropped) instead of
  being read out as brackets and numbers
- One note after a [ - like [dah<2000,24>] - is enough for a message to count as DECtalk singing, wherever the
  note sits inside the brackets. A stray [ on its own or brackets around normal words still don't count.
- DJ: YouTube songs play again. YouTube started refusing its audio links to anything but yt-dlp, so songs
  started and ended at once; yt-dlp now fetches the audio itself and hands it to ffmpeg. If a song can't be
  played, the DJ window says why (e.g. "This video is unavailable").
- Silent keys (the "echo" versions in tts.cfg) work on the first press. TF2 often writes them scrambled
  ("Name !stop :", "!stop Name"), so it could take 2-3 presses; TF2Speech now understands those - from admins
  only. !admin add still has to come through exactly.
- Chat lines are only read once TF2 has finished writing them, so a message is never cut in two and a command
  is never handled twice.


v1.1.0 - changes since v1.0.0
=============================

NEW
---
- DJ window: play music from your PC, your Subsonic/Navidrome library or YouTube into voice chat. Queue, music
  gets quieter while a voice talks, loudness levelling, bass control, "now playing", a DJ voice, chat song
  requests (!sr) with spoken confirmations, optional approval (!approve / !deny), a per-person limit, and
  !skipsong for admins
- Chat soundboard (Sven Co-op ChatSounds style): type a word like "yee" and everyone hears the sound
- Voices tab: make Windows' extra voices usable (one admin prompt, with Undo) and download free Piper voices
- Classic SAPI 4 voices (Microsoft Sam 4.0, TruVoice...) if they're installed, with a ready-made [SAPI4] Bonzi
- Optional TextAloud voices (e.g. Acapela Will From Afar) - TextAloud runs hidden, crashes and freezes are handled
- New look: flat Light / Dark / Match Windows, or the Classic look. Resizable sections with draggable dividers,
  smooth resizing, tabs that scroll instead of being cut off, remembers its size and position, sharp at any
  Windows scaling
- Mutes: !mute [minutes] / !unmute, a MUTED panel and automatic muting of copy-paste spam
- Multiple games: add, edit and remove any Source game (L4D2, GMod, CS:S...) with its own log file, admins and
  block list
- DECtalk auto-switch: DECtalk commands ([:np], [dah<600,20>]...) sent with another voice are spoken with DECtalk
  instead of read out as gibberish
- Help tab rewritten to match the real commands
- tts.cfg: keys for mute, approve, deny and skip song, plus optional silent versions of the keys
- No console window; start-up errors show in a pop-up

FIXES
-----
- Privacy: tts_tf2.log no longer contains what people say in chat - only how long a line was, the voice and
  the player's name - and it's capped at about 10 MB (tts_tf2.log plus the previous one as tts_tf2.log.1).
  You can delete an old tts_tf2.log from v1.0.0, which may contain chat.
- Muting or blocking someone cuts their current line off immediately (Windows voices too)
- Admin commands still work for an admin who is muted
- "Hide / Unhide Selected" really hides voices - from every voice list and from random voices
- Drop-down lists follow the theme after switching it
- Spectators (*SPEC*) are matched against blocks, mutes and voices
- Status-command and material-error lines no longer clutter the chat window
- Windows voices read text literally (no SAPI markup tricks like minutes of silence)
- Each queued message keeps its own voice
- Settings are saved safely: no half-written config.json, and a backup is kept and used if the config is damaged
- "✓ Apply" saves everything on the Settings tab; Import / Export keep all settings; Import, Reset and Reload
  really apply
- !block never blocks the program's own speakers; a DECtalk default voice is honoured
- DECtalk: the volume slider also applies to profile tests and goes up to 150%; output device matching skips
  input devices
- Old temp files from crashed runs are cleaned up automatically
- No hard-coded default admin name
- Removed the "Output to TF2 Chat" and "Test Audio" buttons, which didn't work
- tts.cfg: voice_buffer_ms is 100 (lower made other players sound choppy for you)

RELEASE
-------
- The download now includes the licences of everything built into the exe (THIRD-PARTY-NOTICES.txt) and notes
  on every kind of voice (VOICES.txt)
- Smaller exe: two unused libraries are no longer built in
- ffmpeg, yt-dlp and Piper are downloaded on demand from their official sources - nothing extra is bundled or
  installed
- Building from the GitHub source now includes DECtalk's language files (they were missing from the repository)
